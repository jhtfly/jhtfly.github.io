## 你好，欢迎来到浩涛工作室

这是站点的第一篇文章。浩涛工作室不是一个公司，而是一个人的工作台——把日常工作里的技术实践、日常在用的 AI 提示词、以及周末折腾的量化研究，都安放在这里。

## 这个站里有什么

- **文章**：技术笔记与方法论，重点是 Python 数据分析、文档自动化、AI 提示词和量化研究
- **实验室**：一个可以一键复制的提示词库，加上我做的小作品（比如你现在看到这个网站）
- **关于 / 联系**：我是谁、怎么找到我

## 为什么叫“工作室”

MBA 的同学找我写表格工具、做课表查询页，做的“活”越来越多，索性给这些产出起了个名字。工作室的“产品”目前有两类：给自己省时间的工具，和给同学同事用的小站点。

## 网站怎么更新的

网站托管在 GitHub Pages 上，纯静态、无后端。更新文章有两条路：

1. 把内容发给我（或者自己写好 Markdown），放进 `posts` 目录推送上线
2. 直接在 GitHub 网页上编辑仓库里的文件，保存即发布
